# AI Usage Disclosure

## 1. AI Tools Used

The following AI tool was used during the development of this project:

- ChatGPT

---

## 2. How AI Tools Were Used

### ChatGPT

ChatGPT was used for:

- Understanding the selected research paper and its experimental methodology.
- Understanding the XAI methods used in the paper, including Superpixel, CAM, FAM, and Random.
- Understanding the CUB-200 occlusion and inclusion experiments.
- Debugging Python and PyTorch errors.
- Troubleshooting dataset paths and the experimental environment.
- Developing optimized/batched versions of the experimental code to reduce execution time.
- Interpreting experimental outputs.
- Generating and validating result visualizations.
- Organizing the Phase 1 replication documentation.

---

## 3. Prompts / Tasks Used

The main prompts and tasks given to the AI tool included:

1. Explain the selected research paper in detail.
2. Explain the XAI methods used in the paper.
3. Help reproduce the CUB-200 experiments from the paper.
4. Help configure the Python/PyTorch environment for the replication.
5. Debug errors encountered while running the original repository.
6. Help implement a faster/batched version of the experiment while preserving the experimental methodology.
7. Help generate the result graphs and calculate the corresponding statistics.
8. Help interpret and validate the replication results.

The prompts were used as development, debugging, explanation, and documentation assistance rather than as a substitute for experimental verification.

---

## 4. How AI Output Was Modified and Verified

AI-generated suggestions and code were reviewed and tested before being incorporated into the project.

The generated code was modified where necessary to match:

- The existing repository structure.
- The CUB-200 dataset structure.
- The available Python and PyTorch environment.
- The existing model implementation.
- The experimental methodology described in the selected paper.

Experimental code was executed locally and the generated results were checked using the available NVIDIA RTX 3050 GPU.

The generated CSV files and figures were inspected and validated after execution.

AI-generated explanations and documentation were also reviewed and edited to ensure that the final submission accurately represented the experiments that were actually performed.

The final experimental results and project decisions were reviewed by the student before submission.
