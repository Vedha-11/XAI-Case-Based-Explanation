# Statement of AI Usage

This project utilized AI assistance tools during the paper analysis, experiment replication, environment troubleshooting, and repository organization.

## AI Tools Used

1. **ChatGPT (OpenAI)**
2. **Antigravity / AI Coding Assistant (Google DeepMind)**

## Areas of Assistance

- **Paper Understanding**: Parsing complex methodology and post-hoc case-based explanation formulations from the IJCAI 2023 paper.
- **Debugging**: Resolving code discrepancies, data loader paths, and evaluation metrics handling in PyTorch and scikit-image.
- **Environment Troubleshooting**: Navigating dependency updates (PyTorch, torchvision, scikit-learn, scikit-image) and managing environment settings.
- **Experiment Optimization**: Assisting in structuring evaluation workflows for occlusion/inclusion experiments across superpixel segmentations.
- **Project Organization**: Formatting and structuring the repository for GitHub submission, preserving result integrity, and maintaining directory hygiene.
- **Documentation Assistance**: Formatting markdown documentation, dataset guides, READMEs, and report summaries.
